# P-Community

一个开放的开源社区。聊聊你在做什么，分享有意思的项目，或者提出一个还没想清楚的点子。不用先有项目、代码或完整的提案。

## 从这里开始

- **[随便聊 · Issue #1](https://github.com/pengpengyi92/p-community/issues/1)**：来打个招呼、聊近况，或分享最近发现的好工具。直接在原帖留言就行。
- **[Discussions](https://github.com/pengpengyi92/p-community/discussions)**：值得单独聊的话题可以开一帖。欢迎开源经验、项目想法、合作邀请，以及对社区的具体建议。

中英文都欢迎。可以不同意，但请针对观点交流。帖子是公开的，请不要发布隐私、密钥或未经许可的材料。

English is welcome. Say hello in [Open Chat](https://github.com/pengpengyi92/p-community/issues/1), or start a [Discussion](https://github.com/pengpengyi92/p-community/discussions) for a topic of its own.
